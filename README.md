# Synaps

Synaps adalah aplikasi manajemen tugas dan aktivitas perkuliahan. Aplikasi ini membantu pengguna melihat daftar tugas, deadline, prioritas, dan status tugas dan juga pengguna bisa menyatukan seperti pencatatan uang dan penambahan kelola keuangan bisnis

## Teknologi
- HTML5
- Bootstrap 5.3.3 melalui CDN
- CSS tambahan pada `style.css`

## Halaman
- `index.html` — dashboard dan ringkasan tugas
- `detail-tugas.html` — daftar dan ringkasan detail tugas
- `tambah-tugas.html` — formulir tambah tugas

## Cara menjalankan
1. Unduh atau clone repository.
2. Buka folder proyek di VS Code.
3. Jalankan `index.html` menggunakan browser atau ekstensi Live Server.
4. Koneksi internet diperlukan untuk memuat Bootstrap CDN.

## Alasan memilih Bootstrap
Bootstrap dipilih karena menyediakan komponen siap pakai seperti navbar, card, tabel, dan form. Grid Bootstrap juga memudahkan pembuatan layout yang responsif, sehingga cocok untuk kerangka awal Synaps dan membantu proses pengembangan tampilan menjadi lebih cepat.
